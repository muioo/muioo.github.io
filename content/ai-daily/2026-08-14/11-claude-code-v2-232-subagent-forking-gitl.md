## 摘要

Claude Code v2.1.232 默认启用 subagent forking，子代理可继承完整对话与提示缓存，交互会话中的非队友代理默认后台运行。新增 GitLab token 密钥脱敏、插件市场 GitLab 仓库克隆支持，并修复 PowerShell 与 Windows 权限绕过、嵌套 git 仓库信任继承等多项安全漏洞。

## 摘要

Claude Code v2.1.216 修复了长会话中消息归一化成本随轮次二次增长导致的数秒停顿问题，并修正了 OAuth token 过期后自动模式误判 HTTP 401、后台子智能体重启后恢复默认配置、以及工作树隔离子智能体重定向 git 目录等多项缺陷。新增 `sandbox.filesystem.disabled` 设置，可在保留网络出口控制的同时跳过文件系统隔离。

## 摘要

Claude Code v2.1.208 发布。新增屏幕阅读器模式，可通过 `claude --ax-screen-reader` 等启用。新增 `vimInsertModeRemaps` 设置，支持映射双键序列为 Escape。新增 `CLAUDE_CODE_PROCESS_WRAPPER`，允许通过包装可执行文件启动所有自生成进程。修复了快速模式未自动恢复、后台会话因二进制替换导致附加失败、上下文窗口重置为 200k 等问题。优化了多 MCP 工具场景下的工具轮次性能，并将会话转录体积大幅缩减。

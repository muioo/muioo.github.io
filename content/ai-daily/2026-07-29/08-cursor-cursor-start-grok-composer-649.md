## 摘要

Cursor 面向印度开发者推出新订阅计划 Cursor Start，月费 ₹649（含税），支持 UPI 支付。该计划提供对 Grok 4.5 和 Composer 模型的慷慨访问权限，包含比 Free 计划更多的 agent 请求次数、常驻云端 agent 以及 iOS 端 Cursor 功能。印度已成为 Cursor 第三大市场，用户数超 300 万，且人均 agent 请求量全球最高。

## 摘要

Apple 研究人员提出一种无需可执行环境即可生成高质量训练数据的方法，用于训练 API 调用型大语言模型（LLM）智能体。该方法仅需 API 规格说明，利用 LLM 作为数字世界模型，通过教师智能体与 LLM 模拟器交互生成轨迹，并由 LLM 裁判过滤。在 AppWorld 和 OfficeBench 基准上，微调模型使用该合成数据取得了显著的性能提升。

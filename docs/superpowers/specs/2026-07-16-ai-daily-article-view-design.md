# AI 日报文章化展示设计

## 背景

AI 日报爬虫当前使用 Hugo branch bundle 结构生成内容：

- `content/ai-daily/{date}/_index.md`：当天日报索引，包含按分类组织的新闻标题和摘要。
- `content/ai-daily/{date}/{NN}-{slug}.md`：单条新闻详情。
- `data/ai-daily/latest.json`：最近日报日期索引。

日期页（例如 `/ai-daily/2026-07-15/`）目前由 `layouts/ai-daily/list.html` 渲染。该模板遍历日期目录下的子页面并输出折叠列表，没有渲染 `_index.md` 的 `.Content`，因此页面表现为目录，而不是一篇可连续阅读的日报文章。

## 目标

1. 日期页以标准文章形式展示当天完整日报。
2. 同一页面按分类依次展示全部新闻标题和摘要。
3. 新闻标题继续链接到对应的单条详情页。
4. 顶层 `/ai-daily/` 继续作为历史日报归档页。
5. 导航栏“AI 日报”在每次 Hugo 构建时自动指向最新日期页。
6. 备用入口 `/ai-daily-entry/` 同样跳转到最新日期页，不得跳转到单条新闻详情。

## 非目标

- 不改变爬虫 API、抓取流程或 branch bundle 文件结构。
- 不把单条新闻全文合并到日期页。
- 不删除历史日报或单条详情页。
- 不引入浏览器端 API 请求或 JavaScript 内容拼接。
- 不调整与 AI 日报无关的主题样式和内容。

## 方案选择

采用模板分流方案：根据当前页面是否为日期格式的 AI 日报 section，选择文章视图或归档视图。

未采用以下方案：

- 将每天日报改成单个 leaf page：会破坏现有详情页和 branch bundle 结构，改动范围过大。
- 使用 JavaScript 动态拼接日报：增加客户端依赖，不利于静态生成、SEO 和无脚本访问。

## 页面设计

### 日期页

匹配 `/ai-daily/YYYY-MM-DD/` 的页面使用文章布局：

- 使用 Stack 主题现有的文章容器、标题、正文和页脚组件。
- 页面标题来自 `_index.md` 的 front matter。
- 页面正文渲染 `_index.md` 的 `.Content`。
- Markdown 二级标题作为新闻分类。
- Markdown 三级标题作为新闻标题，并保留现有详情页链接。
- 标题下方显示爬虫已经生成的摘要。
- 关闭评论的现有 `comments: false` 配置保持不变。
- 右侧栏按文章页面规则显示目录；存在足够长的目录时可按分类快速跳转。

### 顶层归档页

`/ai-daily/` 保持现有归档行为：

- 按月份分组。
- 显示每天日报的日期和标题。
- 点击日期进入对应日期页。
- 不在归档页展开当天全部新闻。

## 最新日报导航

导航栏继续从 Hugo 页面集合中获取 `/ai-daily` 的直接子页面，按日期倒序选择第一项。直接子页面均为日报日期页（新结构为日期 section，旧归档为顶层日期 Markdown），不包含日期目录内的单条新闻详情。

当爬虫生成 `content/ai-daily/2026-07-16/_index.md` 并完成下一次 Hugo 构建后，导航目标自动变为 `/ai-daily/2026-07-16/`，不需要写死日期或修改菜单配置。

`layouts/page/ai-daily-redirect.html` 应采用相同的日期页选择规则。当前实现基于 `.Site.RegularPages`，会排除日期 section 并从其单条新闻详情中选择目标，因此需要改为从 `/ai-daily` section 的直接子页面中选择最新日期页。

如果尚无任何日期页：

- 导航保留现有静态入口地址。
- 备用入口显示“当前还没有可用的 AI 日报内容”。
- 不执行空地址跳转。

## 涉及文件

- `layouts/ai-daily/list.html`：区分日期页与顶层归档页，并在日期页渲染文章正文。
- `layouts/page/ai-daily-redirect.html`：只从日期 section 中选择最新日报。
- `assets/scss/custom.scss`：仅在主题默认文章样式无法覆盖日期页时补充最少量样式。
- `AGENTS.md`：记录日期页文章视图和最新日报导航规则。
- 测试文件：补充能验证日期页、归档页和最新日期选择的回归测试；测试位置遵循项目现有结构。

## 数据流

1. 爬虫请求当天 AI 日报 API。
2. 爬虫生成日期 `_index.md` 和单条详情 Markdown。
3. Hugo 构建识别日期目录为 AI 日报 section。
4. 日期 section 使用文章视图渲染 `_index.md` 正文。
5. 顶层 AI 日报 section 使用归档视图渲染日期列表。
6. 左侧导航与备用入口从日期 section 集合选择最新日期。

## 错误处理

- 日期页存在但正文为空时，仍显示文章标题，不伪造新闻内容。
- 没有日期页时，备用入口显示明确提示并停止跳转。
- Hugo 模板选择逻辑只依赖 section 层级和日期路径，不依赖客户端时间，因此历史构建可重复。
- 构建错误必须由 Hugo 命令正常返回非零状态，不通过模板静默隐藏。

## 验证与测试

至少覆盖以下场景：

1. 构建 `2026-07-15` 日期页，确认正文包含分类、新闻标题和摘要。
2. 确认日期页不再出现按月份折叠的新闻目录。
3. 确认新闻标题链接指向对应的 `/ai-daily/2026-07-15/{slug}/` 详情页。
4. 构建顶层 `/ai-daily/`，确认仍显示月份和日期归档。
5. 同时存在 `2026-07-15` 与 `2026-07-16` 时，确认导航和备用入口均指向 `/ai-daily/2026-07-16/`。
6. 不存在任何日期页时，确认备用入口显示无内容提示且不输出跳转脚本。
7. 运行 Hugo 完整构建，确认没有模板错误或断链警告。
8. 在桌面端和移动端检查文章宽度、标题换行、摘要间距和右侧目录。

## 成功标准

- 日期 URL 呈现为一篇连续可读的完整日报文章。
- 当天全部新闻标题和摘要按原分类顺序显示。
- 每个新闻标题均可进入现有详情页。
- 顶层日报归档功能保持不变。
- 新日期生成并部署后，导航和备用入口无需人工修改即可指向最新日期。
- Hugo 构建和相关自动化测试通过。
